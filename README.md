This program writes one short poem about agency — two agents agreeing on one plan — and runs offline with the Python standard library only.

## Run it

```sh
python3 main.py
```

It writes `entry.txt` inside `/output` (or the directory pointed to by `MAKEFUN_OUTPUT_DIR`).
